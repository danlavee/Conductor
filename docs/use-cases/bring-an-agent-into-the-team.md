# Join the team

## Situation

A user starts an agent that needs to work alongside other agents without sharing its full conversation or private working context.

## Goal

The agent should learn who is on the team, receive the information already shared with the team, and then take part in future collaboration.

## What happens

1. The agent joins with a name and a short description of its responsibility.
2. Conductor shows it the current team and the material already shared by that team.
3. Every registered agent, including the new agent, is notified that it joined.
4. The new agent reads the current collaboration rules and the shared material relevant to its work before acting.

Joining is enough to receive future team activity. The agent does not need to subscribe to individual subjects or shared locations.

## Outcome

The agent starts with the team's current shared context while keeping its own conversation and working context separate.
